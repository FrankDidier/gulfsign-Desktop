二、功能详解
------------

1. 登录功能
   - 支持网页跳转登录，直接在浏览器中登录3.0系统
   - 自动保存登录配置（密码加密存储）
   - 连接诊断功能，测试网络连通性

2. 查询功能
   - 查询状态: 未签约（默认）
   - 机构代码: 可选过滤条件
   - 姓名过滤: 支持模糊搜索
   - 身份证过滤: 精确匹配

3. 签约功能
   - 签约医生: 家庭医生（默认）
   - 签约团队: 家庭团队（默认）
   - 协议日期: 自动设置为一年期限
   - 操作延迟: 0.5秒（防止频繁请求）
   - 最大签约数: 2（测试模式）

4. 批量处理
   - 最大工作线程: 20
   - 批量大小: 2
   - 支持并发处理，提高效率

三、操作流程
------------

1. 登录阶段
   ```
   启动应用 → 输入账号密码 → 网页跳转登录 → 浏览器登录3.0系统 → 返回应用
   ```

2. 查询阶段
   ```
   设置查询条件 → 点击"查询" → 查看未签约居民列表 → 选择要签约的居民
   ```

3. 签约阶段
   ```
   设置签约配置 → 点击"开始签约" → 查看进度和日志 → 等待完成 → 查看结果
   ```

四、配置说明
------------

1. 配置文件位置: `gulfsign_config.json`
2. 主要配置项:
   - username: 登录账号
   - password: 加密存储的密码
   - ggws_base_url: 系统地址
   - doctor: 签约医生
   - team: 签约团队
   - max_workers: 工作线程数
   - batch_size: 批量大小

3. 配置恢复:
   - 应用程序启动时自动恢复上次配置
   - 密码需要重新输入（安全设计）
   - 其他配置自动填充

五、常见问题
------------

Q1: 应用程序启动时崩溃，显示"'_tkinter.tkapp' object has no attribute 'var_url'"
A1: 此问题已修复。请确保使用最新版本。

Q2: 登录时提示"系统地址缺失"或"账号缺失"
A2: 请检查配置文件是否正确，或重新输入账号密码。

Q3: 查询不到未签约居民
A3: 请检查:
   - 网络连接是否正常
   - 账号是否有查询权限
   - 查询条件是否设置正确

Q4: 签约失败
A4: 请检查:
   - 医生和团队信息是否正确
   - 居民是否已被其他医生签约
   - 系统服务是否正常

Q5: 密码显示为"未设置"
A5: 这是正常的安全设计。密码被加密存储，需要每次手动输入。
