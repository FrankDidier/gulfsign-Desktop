===============================================================================
五、常见问题与解决方案
===============================================================================

【问题1】导入错误：No module named 'Crypto'
原因：缺少pycryptodome库
解决方案：
1. 安装pycryptodome：pip install pycryptodome
2. 如果已安装，检查Python路径：python -c "import sys; print(sys.path)"
3. 重新安装：pip uninstall pycryptodome && pip install pycryptodome

【问题2】配置文件加载失败
原因：配置文件格式错误或路径不正确
解决方案：
1. 检查配置文件路径：ls -la gulfsign_config.json
2. 验证JSON格式：python -m json.tool gulfsign_config.json
3. 检查文件权限：chmod 644 gulfsign_config.json

【问题3】加密功能报错
原因：加密密钥不正确或加密算法不支持
解决方案：
1. 检查加密密钥配置
2. 验证加密算法支持：python -c "from Crypto.Cipher import AES; print('AES支持正常')"
3. 重新生成加密密钥

【问题4】批量处理速度慢
原因：并发数设置不合理或网络延迟
解决方案：
1. 调整max_workers参数（建议2-5之间）
2. 检查网络连接
3. 优化任务处理函数

【问题5】Excel日志文件无法创建
原因：文件权限不足或磁盘空间不足
解决方案：
1. 检查目录权限：ls -la logs/
2. 检查磁盘空间：df -h
3. 安装pandas库：pip install pandas openpyxl
