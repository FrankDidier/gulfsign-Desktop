============================================================
        竞品全程录制工具 · 使用说明（超简单）
============================================================

【这个工具做什么】
把对方软件签约时的全部网络流量完整录下来，打包成一个 ZIP 文件，
你发回给我们，我们就能分析出对方是怎么做到的。
全程不影响你正常上网，结束后自动还原电脑设置。


【准备条件】
- Windows 电脑（和对方软件装在同一台电脑上）。
- 电脑能联网（首次运行需要下载几个小组件）。
- 已安装 Python 3。若没装：到 https://www.python.org/downloads/ 下载安装，
  安装时务必勾选 “Add Python to PATH”。


【使用步骤】
第 1 步：把这个文件夹整个解压出来（不要在压缩包里直接运行）。

第 2 步：找到「一键录制.bat」，右键 →【以管理员身份运行】。
        （会弹出权限确认，点【是】。）

第 3 步：窗口里会自动安装组件，然后问你一句话：
        “是否需要抓取对方软件本体的请求？”
        → 直接按【回车】（默认 Y，推荐）。

第 4 步：当看到 “★★★ 录制已就绪 (READY) ★★★” 后，按提示操作：
        1) 先把对方软件【完全关闭】（如果它开着，必须先彻底关掉）。
        2) 重新打开对方软件，扫码登录。
        3) 像平时一样，用对方软件完整做一次签约，直到提示成功。
        （这期间窗口会实时跳出捕获到的请求，带 ★关键流 的最重要。）

第 5 步：签约完成后，回到这个黑色窗口，按【回车】结束。
        工具会自动停止、还原设置，并在你的【桌面】生成一个 ZIP 文件，
        文件名形如：竞品录制_20260619_090000.zip

第 6 步：把桌面上这个 ZIP 文件发回给我们即可。完成！


【常见问题】
Q：运行后对方软件 / 网页打不开（提示“连接已重置”）？
  → 本版本已修复该问题。如果仍出现，先按回车结束本工具（会自动还原），
    再重新运行一次；并确认是在“录制已就绪”之后才重启对方软件的。

Q：结束后提示“没有录到任何流量 / 共 0 条”？
  → 多半是对方软件在“录制已就绪”之前就开着。请重新运行本工具，
    在看到“录制已就绪”后，再【完全重启】对方软件并签约。

Q：提示没有检测到 Python？
  → 按上面【准备条件】里的说明安装 Python，安装时勾选
    “Add Python to PATH”，然后重新运行「一键录制.bat」。

Q：会不会泄露隐私 / 影响电脑？
  → 录制只在本工具运行期间生效，按回车结束后会自动取消代理和证书设置。
    录制内容只保存在你本机的桌面 ZIP 里，由你自己决定发给谁。


【需要帮助】
运行中任何一步卡住，把黑色窗口的截图发给我们即可。
