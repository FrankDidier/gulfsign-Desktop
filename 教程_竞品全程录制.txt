============================================================
            竞品全程录制 · 操作教程
============================================================

【这一步要解决什么】
我们已经基本看明白了对方软件的套路：它用一个自动浏览器登录公卫3.0，
在系统里把签约直接写成「居民申请」（也就是签约状态那一栏从「医生申请」
变成「居民申请/用户申请」），而「居民申请」是可以让医生直接点「确认」
变成「已签约」的。

现在还差最后一块拼图——对方到底是调用哪个网址、用哪个字段把状态写成
「居民申请」的。只要把对方软件签约时的全部网络请求原原本本录下来，
我们离线一比对就能找到，然后照着做。

这就是本页「竞品全程录制」的用途：把对方签约全过程的所有流量完整保存。


【准备】
1. 在同一台电脑上同时装好「对方软件」和我们的「湾流签约助手」。
   （必须是同一台电脑，因为录制的是这台电脑发出的网络请求。）
2. 录制期间不要开别的抓包/代理工具。


【操作步骤】
第 1 步：打开湾流签约助手，切到最后一个标签「竞品全程录制」。

第 2 步：点「● 开始录制」。
   - 会弹出安装证书的确认，请点「是 / 允许」。
   - 看到状态变成绿色「录制中」、日志出现「系统代理已设置」即可。

第 3 步：★重要★ 现在再去打开对方软件并登录、签约。
   - 如果对方软件在你点「开始录制」之前就已经打开/登录了，
     请把它【完全关掉再重新打开】，否则它可能不走我们的录制通道。
   - 然后按你平时的用法，用对方软件完整做一次签约
     （登录 → 打开家医签约页 → 查询 → 开始签约 → 直到提示成功）。

第 4 步：界面中间的表格会实时跳出请求。
   - 黄色高亮 = 可能就是「把状态写成居民申请」的关键请求。
   - 双击任意一行可以查看这条请求的完整内容。

第 5 步：对方软件提示签约成功后，回到本页点「■ 停止并打包」。
   - 会让你选择保存位置，文件名形如「竞品录制_日期时间.zip」。
   - 保存好这个 ZIP，发回来给我们即可。


【就这么简单】
开始录制 → 重启并操作对方软件签约一次 → 停止并打包 → 把 ZIP 发回来。


【如果对方软件 / 网页打不开（连接已重置 ERR_CONNECTION_RESET）】
对方软件如果是用 Python(requests) 联网，它默认只认自带的证书库、不认我们
装到系统里的证书，于是经过我们录制通道时会握手失败、连接被重置——表现就是
对方软件报错、浏览器打开 ggws 显示「无法访问此网站 / 连接已重置」。

两种处理方式，按需选择：

方式 A（只想确认不影响使用 / 抓浏览器流量就够）：
   新版已自动处理——遇到不信任证书的程序会自动『直通放行』，对方软件/网页
   恢复正常访问（这条流量抓不到明文，但不再卡死）。直接重试即可。

方式 B（一定要抓到对方软件本体的请求）：
   1. 开始录制前，勾选「让对方软件信任证书（增强捕获）」。
   2. 点「● 开始录制」。
   3. ★必须★ 完全关闭对方软件再重新打开（它启动时才会读取新设置）。
   4. 再用对方软件签约。这样它就会信任我们的证书，明文就能被抓到。
   5. 「停止并打包」时会自动还原设置，不影响以后正常使用。


【常见问题】
Q1：点「停止并打包」后提示「未捕获到任何公卫域名流量」。
   → 多半是对方软件在开始录制之前就已经在运行了。请：
     先停止录制 → 完全关闭对方软件 → 重新「开始录制」→ 再重新打开
     对方软件做签约。

Q2：对方软件报证书错误 / 连不上？
   → 这是因为我们的录制证书还没被信任。点开始录制时弹出的证书安装
     确认要选「是 / 允许」。如仍不行，停止录制后重试一次。

Q3：录完想确认有没有录到东西？
   → 点「打开录制目录」，里面每条请求都是一个 .txt 文件，
     还有一个 _index.jsonl 总索引。有文件就说明录到了。

Q4：会不会影响电脑上网或泄露隐私？
   → 录制只在「录制中」期间生效，点「停止并打包」后会自动取消系统代理。
     录制内容只保存在本机，由你打包后自行发送。用完建议删除证书
     （流量抓包页有相应说明）。

Q5：表格里没有黄色高亮的行怎么办？
   → 没关系。我们要的是「全部」流量，黄色只是辅助提示。
     只要 ZIP 里有文件，发回来我们都能逐条分析。


【录制时大致会看到对方软件的流程】（供参考，你不用对照操作）
   1) 对方软件启动一个自动浏览器，用你的3.0账号登录
   2) 提示你打开家医签约界面、设置筛选、点一下查询
   3) 它在后台把签约写进系统（这一步产生的请求就是我们要抓的）
   4) 居民的签约状态变成「居民申请 / 用户申请」
   5) 医生点「确认」即变「已签约」
